# KCET Survival Board

Deploy-ready React/Vite version of the uploaded KCET Survival Board.

## Run locally

1. Install Node.js LTS.
2. Open a terminal in this folder.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the localhost URL shown by Vite.

## Build for deployment

Run `npm run build`.

The generated `dist` folder can be deployed to Vercel, Netlify, GitHub Pages (with suitable configuration), or another static hosting provider.
